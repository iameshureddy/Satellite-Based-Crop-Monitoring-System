# 🌾 AgroVision: AI-Powered Satellite Crop Monitoring & Agricultural Intelligence System

## 🚀 Overview

AgroVision is an advanced precision agriculture platform that leverages satellite imagery, geospatial analytics, weather intelligence, and machine learning to monitor crop health, analyze field conditions, predict agricultural outcomes, and support data-driven farming decisions.

The platform integrates Google Earth Engine, Sentinel satellite data, NDVI analytics, crop stress detection, weather monitoring, and yield prediction into a unified dashboard for farmers, researchers, agronomists, and agricultural stakeholders.

---

## 🎯 Key Objectives

* Monitor crop health using satellite imagery.
* Analyze vegetation conditions through NDVI indices.
* Detect crop stress and environmental anomalies.
* Generate actionable agricultural insights.
* Support precision farming practices.
* Improve productivity through data-driven decisions.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/iameshureddy/Satellite-Based-Crop-Monitoring-System.git
```

## Navigate to Project Directory

```bash
cd Satellite-Based-Crop-Monitoring-System
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

Linux / Mac:

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```

or

```bash
python app.py
```
